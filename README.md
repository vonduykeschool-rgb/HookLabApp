# Hook Lab

A Drafter website that works as a vault for song fragments. Save lyric and melody ideas tagged by mood, filter them, mark favorites, and shuffle them into random 4-line stanzas.

- **Live site:** https://vonduykeschool-rgb.github.io/HookLabApp/
- **Planning document:** [plan.pdf](plan.pdf)
- **Walkthrough video:** [_Short_Demo_](https://youtu.be/CxDDnozqGio)
